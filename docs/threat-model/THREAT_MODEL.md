# Potenova Threat Model — Skeleton (WP-00)

Seeded from `06_Security_Privacy_Child_Threats.md` (TM-01..50). This is the WP-00 **skeleton**: each case has a scenario, primary trust boundary, required mitigation, owner, and where it is verified. Rows marked **FITNESS TEST (WP-00)** are already enforced as executable guards in `@potenova/domain-core` and covered by tests; the remainder are scheduled at their work package. Full negative-test authorship and sign-off complete in **WP-11** (and per-WP as capabilities land). SEC-004 requires this model be completed before significant child-facing capability.
