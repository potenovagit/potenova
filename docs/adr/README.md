# Architecture Decision Records

ADR numbering follows the mandatory ADR set in `08_Claude_Implementation_Work_Packages.md`
(ADR-001..016). WP-00 authors the **foundational / gating** ADRs in full (Proposed, pending the
G0 approval gate) and records a one-line **proposed stance** for the rest, to be authored at
their work package. No ADR is "approved" merely because it was drafted here (Governance §5).

| ADR                                                  | Topic                                             | Status                          | Stance (summary)                                                                                                                                                                                      |

| [0001](0001-platform-architecture-and-boundaries.md) | App/platform architecture & deployable boundaries | **Proposed**                    | TypeScript **modular monolith** (14 module boundaries) + isolated AI/ingestion workers; React + React Native clients. No premature microservices.                                                     |
| [0002](0002-persistence-and-immutable-evidence.md)   | Persistence & immutable evidence                  | **Proposed**                    | Managed **PostgreSQL (Canada)**; append-only `evidence_event`; `LearnerSkillState` as replay-built projections.                                                                                       |
