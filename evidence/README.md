# Evidence repository

Layout (from `07_Acceptance_NFR_Release_Gates.md` §D):

```
/evidence/<gate>/<requirement-id>/<run-id>/
```

Each run artifact records: test report, **synthetic** fixture IDs, redacted trace, reviewer,
software/model/content/policy versions, date, actual vs expected result, and any
exception/risk approval. **Never** place child content in evidence folders or tickets.

## WP-00 (G0 architecture acceptance)

- `WP-00/requirement-trace.json` — v2 register import + shape gate (276 reqs / 16 domains /
  all LOCKED / WP-00=15). Regenerate: `npm run trace:evidence`.
- Architecture-fitness test results (mastery authority, AI routing, content gate, consent
  fence, evidence immutability) are produced by `npm run test` in CI and uploaded as the
  `wp-00-evidence` artifact.

## G2 (controlled-beta gate) — in progress

- `G2/AI-003/<run-id>/report.json` + `summary.md` — candidate-model evaluation on the
  synthetic fraction suite (AI-003; ER-16 quality/safety evaluation). Generated by
  `npm run eval:model` against the in-Canada Azure OpenAI deployment
  (`AZURE_OPENAI_ENDPOINT`/`DEPLOYMENT`/`KEY`). Synthetic data only; nothing is delivered
  to a child. The gate property is **containment** — every incorrect answer must be
  blocked/fallen-back, never delivered — recorded as `result: PASS|FAIL`. The `reviewer`
  field is left null until a human signs the artifact toward the gate.

- `G2/GATE-DRYRUN/<run-id>/report.md` + `transcript.json` — Stage-2 gate-checklist
  dry-run: an end-to-end pass that stands up the live API over an in-memory synthetic
  database and drives it through each fail-closed non-negotiable at the HTTP edge
  (consent fence incl. revocation, content gate, Canadian residency, mastery-authority
  integrity + tenant isolation, right-to-erasure incl. fail-closed-until-attested,
  retention dry-run, AI-routing fail-closed), recording actual status/code vs expected.
  Regenerate: `npm run gate:dryrun`. Synthetic only; no model, no child data, no child
  content in the transcript. It demonstrates the MECHANISMS hold — it is **not** the
  specialist sign-off that decides the policy VALUES (privacy/legal, child-safety,
  accessibility). The CI test `gate-dryrun.test.ts` fails if any gate regresses.

- `G2/ER-03/<run-id>/report.md` + `evidence.json` — ER-03 conceptual-mastery
  evidence pack: drives the **authored** conceptual probes (both assessed-core
  skills — equivalence and comparison — at Grades 3–5) through the production
  scorer and evaluator. Each (skill × grade) set is run correct (→ INDEPENDENT)
  and with the reasoning probe answered wrong (→ NOT_YET_DEMONSTRATED, reasoning
  unmet), demonstrating that a right answer with wrong reasoning earns no mastery.
  `evidence.json` holds the raw synthetic events. Regenerate: `npm run er03:evidence`.
  The CI test `er03-evidence.test.ts` fails on any regression. CANDIDATE policy,
  advisory; synthetic only; no child, no model.

Gate directories for G1, G3, G4 are created as those gates are approached.
